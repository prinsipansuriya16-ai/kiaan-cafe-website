# ☕ cafe website — Full-Stack Cafe Ordering & Reservation Platform

A modern, high-converting web platform designed for local cafes and cloud kitchens to increase direct customer orders, handle real-time table reservations, and eliminate **25-30% third-party aggregator commissions** (Zomato/Swiggy).

## ✨ Key Features & Business Impact

### 🛍️ Customer Experience
* **Interactive Digital Menu:** Categorized food selection with real-time availability and dynamic pricing.
* **Flexible Checkout Options:** Supports Cash on Delivery (COD), Takeaway / Pay-at-Counter, and Secure Online Payments.
* **Table Reservation System:** Seamless seat booking to minimize peak-hour wait times.
* **Responsive Mobile-First UI:** Tailored for quick ordering on smartphones via Instagram bio links or QR codes.

### 💼 Owner / Admin Control
* **Zero-Commission Model:** Direct order flow saving cafes 25-30% per delivery.
* **Instant Email & Alert System:** Instant notification triggers sent directly to the cafe owner's email upon new order/reservation entry.
* **Live Admin Dashboard:** Real-time dashboard listening to database row insertions for active order tracking.
* **Flexible Logistics Control:** Designed to support local delivery radius restrictions (e.g., 3km/5km limits) and third-party rider integration (Porter/Borzo).

---

## 🛠️ Tech Stack & Architecture

* **Frontend:** React, TypeScript, Tailwind CSS, Vite
* **Backend & Database:** Supabase (PostgreSQL with Row Level Security & Realtime Listeners)
* **Email & Notifications:** EmailJS / Webhook Triggers
* **Payment Gateways:** Stripe API (Configurable to Razorpay/UPI for local Indian markets)
* **Hosting & Deployment:** Vercel (Continuous Deployment via Git)
